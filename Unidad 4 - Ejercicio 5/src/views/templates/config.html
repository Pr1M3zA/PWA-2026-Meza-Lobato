El navegador ya no mostrará avisos de sincronización para este sitio. Para reactivarlos:

  1. Haz clic en el ícono del candado 🔒 en la barra de direcciones.
  2. Abre “Permisos de este sitio” (o “Configuración del sitio”).

  4. Recarga la página y acepta el aviso de permiso cuando aparezca.

En Firefox: Menú ☰ → Ajustes → Privacidad y seguridad → Notificaciones → “Configuración…” y quita este sitio de la lista de bloqueados.
